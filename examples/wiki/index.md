## What is markdown-wiki?

A CLI tool that turns a folder of Markdown files into a searchable, linkable personal wiki with:

- **Wiki-links**: `[[Page Name]]` syntax for connecting pages
- **Backlinks**: Automatic "Pages that link here" sections
- **Tags**: Organize and filter pages by tags
- **Search**: Full-text client-side search
- **Dark mode**: Respects your system preference
