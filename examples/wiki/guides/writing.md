# Writing Markdown

Your wiki supports full Markdown syntax with some enhancements.

## Text Formatting

- **Bold** text with `**bold**`
- *Italic* text with `*italic*`
- `Inline code` with backticks
- ~~Strikethrough~~ with `~~text~~`

## Code Blocks

```javascript
// Syntax highlighting via CSS classes
function greet(name) {
  return `Hello, ${name}!`;
}
```

## Lists

Unordered:
- First item
- Second item
- Third item

Ordered:
1. Step one
2. Step two
3. Step three
