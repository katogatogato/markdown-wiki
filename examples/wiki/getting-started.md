# Getting Started

Welcome! Here's how to use your wiki effectively.

## Quick Start

1. Create `.md` files in your wiki directory
2. Add frontmatter for metadata
3. Use `[[wiki-links]]` to connect pages
4. Run `markdown-wiki build` to generate HTML

## Frontmatter Reference

```yaml
---
title: My Page Title
tags: [tag1, tag2, tag3]
description: A brief summary of this page
date: 2026-01-15
---
```
